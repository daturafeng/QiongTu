# Benchmark source review

本文件记录任务 1.1 的数据来源与许可筛选证据，不取代 OpenSpec 的需求、设计或任务状态。

## 纳入组合

### 项目所有者提供的私有样例

- 用途：多角度 JPEG/MPO、定位辅助文件和倾斜复杂场景。
- 权限：仅作为项目内部只读样例，未获原始数据再分发授权。
- 隐私：内容身份和详细清点只保存在 Git 忽略的私有本地清单中；公开登记使用逻辑别名和环境变量绑定。
- 限制：不能单独证明精度、跨设备兼容或引擎泛化。

### USGS Fall Creek Lake 2016-11-09

- 官方页面：https://data.usgs.gov/datacatalog/data/USGS%3A5dfd4efae4b0b207aa00a15a
- 持久标识：https://doi.org/10.5066/P9AYWU8Z
- 官方内容：原始航片，并属于同时包含 GCP、点云、DEM、正射、处理报告和范围的发布。
- 许可：官方目录标记为 U.S. Public Domain。
- 用途：独立规则正射、参考成果/精度记录、跨来源回归以及高斯固定留出视角。

### USGS Medina River 2019/2022

- 官方页面：https://data.usgs.gov/datacatalog/data/USGS%3A633c7d3dd34e900e86cf1a53
- 持久标识：https://doi.org/10.5066/P9KN8RG0
- 官方内容：两期 UAS 影像、GCP 信息以及点云、DSM、正射成果。
- 许可：官方目录标记为 U.S. Public Domain。
- 用途：第三个独立物理来源、跨日期和地表场景回归、控制/参考结果验证。

## 未纳入默认商业产品门禁

### MatrixCity

- 官方页面：https://city-super.github.io/matrixcity/
- 优点：航空/街景、相机位姿、深度、法线、训练/测试划分，适合大场景新视角研究。
- 限制：数据页面明确采用 CC BY-NC 4.0；在未获得额外授权和法律确认前，不纳入商业产品的默认基准组合，也不下载。

### OpenDroneMap ODMData 索引

- 官方索引：https://github.com/OpenDroneMap/ODMdata
- 优点：包含多种影像数量、GCP、RTK 和场景组合。
- 限制：索引明确说明数据来自多种来源，但没有在索引中给出统一的数据许可。ODM 软件的 AGPL 许可证不能自动证明各第三方影像的使用与再分发权；必须逐数据集找到原始许可证据后才能纳入。

## 门禁结论

当前批准的组合具有三个相互独立的物理来源，其中两个是许可证据明确的公共领域发布。远端数据尚未下载，内容哈希、文件数量和确定性派生集身份必须在用户批准物化后补齐；在此之前只允许使用所有者私有样例执行本地可行性预演，且不得把暂定阈值、单样例结果或预演成功当成已验证性能或引擎选型证据。
