# Change: 固化总控与执行窗口的模型路由

## Why

穹图已经建立总控式并行开发、有限重试和安全依赖安装规则，但模型选择仍只写成“按用户指定且环境可用”，后续会话无法自动恢复当前已确认的默认路由。需要明确当前窗口作为 GPT-5.6 总控、新建执行窗口优先使用 GPT-5.5，同时在模型目录变化或 Codex 要求重启时避免静默替换、反复创建失败窗口或绕过运行时限制。

## What Changes

- 将当前活动窗口固定为总控角色，默认使用 GPT-5.6 承担 OpenSpec、拆分、集成、复验和状态更新。
- 将新建并行执行窗口的默认模型固定为 GPT-5.5，并只为边界独立、可并行产生价值的任务创建。
- 当指定模型不可用、模型目录在 Codex 启动后变化或当前运行时禁止模型覆盖时，停止创建带覆盖的新窗口，不静默换用其他模型；由总控串行推进安全工作并记录需重启或由用户处理的条件。
- 继续沿用既有有限重试、推荐依赖安装和用户升级门禁，不增加另一套阻塞流程。

## Impact

- Affected spec: `development-governance`
- Affected project rule: `AGENTS.md`
- 不改变穹图产品架构、运行时依赖、用户数据或发布范围。
